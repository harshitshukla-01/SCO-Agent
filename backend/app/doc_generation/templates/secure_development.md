# Secure Development Policy

## Purpose and scope
Define software, repositories, environments, and personnel covered by secure development practices.

## Roles and training
Assign responsibilities for developers, reviewers, security, and release approvers.

## Design and implementation
Set expectations for threat consideration, secure coding, secrets handling, and dependency selection.

## Review and testing
Describe peer review, security testing, findings triage, and documented exceptions.

## Build, release, and change control
Define protected release paths, separation of duties, and rollback expectations.

## Vulnerability handling and review
Describe remediation ownership and policy review cadence.
