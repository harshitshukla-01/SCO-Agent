# Cryptography Policy

## Purpose and scope
Define systems and information requiring cryptographic protection.

## Approved cryptographic use
Describe how approved algorithms, protocols, and libraries are selected and maintained.

## Encryption requirements
Set expectations for data in transit, data at rest, and protected backups.

## Key ownership and lifecycle
Define key generation, storage, access, rotation, revocation, recovery, and destruction responsibilities.

## Exceptions and monitoring
Describe risk approval, configuration review, and handling of cryptographic weaknesses.

## Policy review
Set a review cadence and accountable owner.
